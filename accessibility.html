Accessibility

How we make kidodino.com usable for everyone.

We want every parent and caregiver to be able to use kidodino.com, including people who use a screen reader, a keyboard instead of a mouse, screen magnification, or larger text.

Standard

The site is built to meet Israeli Standard IS 5568, which is based on the Web Content Accessibility Guidelines (WCAG) 2.0 at level AA. We also follow WCAG 2.1 level AA.

What we have done

  • Every page works with a keyboard alone, and the keyboard focus is always clearly visible.
  • A "Skip to main content" link is the first thing on every page.
  • Pages use real headings, landmarks and lists, so screen readers can move around easily.
  • Every meaningful image has a text description. Decorative shapes are hidden from screen readers.
  • Text and background colors meet the WCAG AA contrast ratio, in both light and dark mode.
  • Text can be enlarged to 200% without losing content, and the layout adapts to small screens.
  • Every game works with a keyboard, moves focus to each new step, and can read every instruction aloud.
  • Animation is minimal and turns off when your device asks for reduced motion.

Known limitations

The free coloring pages are pictures meant to be printed and colored. Because they are drawings, a screen reader cannot read them in full. If you would like a description of a page, write to us and we will send one.

Accessibility contact

If something on the site is hard to use, or you need information in another format, please write to kido@kidodino.com. We will reply as soon as we can.
